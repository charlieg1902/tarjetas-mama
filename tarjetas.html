⚙️ Cómo activar la integración con Outlook

Pasos para configurar (una sola vez):

1. Andá a portal.azure.com con tu cuenta de Microsoft
2. Buscá Azure Active Directory → App registrations → New registration
3. Nombre: "Tarjetas al instante" (o el que quieras)
4. Redirect URI: seleccioná Single-page application (SPA) y pegá la URL de este archivo
5. Después de crear, copiá el Application (client) ID
6. En API permissions agregá: Contacts.ReadWrite y User.Read (ambos Delegated)
7. Pegá el Client ID en el código donde dice TU_CLIENT_ID_AQUI

API Key de Claude:
Obtené tu key en console.anthropic.com → API Keys → Create Key.
Se guarda localmente en tu dispositivo, no se comparte.
